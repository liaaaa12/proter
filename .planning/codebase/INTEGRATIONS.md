# External Integrations

## Database

- **SQLite**: Default configured in `.env` and `phpunit.xml` (using `:memory:` for tests). Note: MySQL was mentioned in previous context as a potential target.

## Voice Processing

- **Python Scripts**: Local integration with Python scripts in `scripts/` (e.g., `voice_processor.py`, `voice_processor_ecapa.py`).

## APIs

- **Kaggle**: Used for downloading datasets (Indonesian Speech dataset).

## UI/UX

- **Inertia.js**: Bridging Laravel and React.
- **Vite**: Bundling and refreshing assets.
